About these prototypes
Purpose
Compare building a dashboard from existing LookML with building one from a metrics file when no LookML exists.
Look and feel
All three dashboards share the same design, navigation and chart library, so they can be compared on how they are built, not how they look.
Definitions
Each dashboard lists the questions it answers and the rule behind each number. Hover or expand on the page for details.
Privacy
Pages show counts and averages only, never individual records. The member overview hides groups with fewer than 11 members.
Status
Prototype. Numbers have not yet been checked against Looker or by the data owners, and the definitions marked "default" need an analyst's review.
